## Can 历史失败的准确范围

读取 V34 `open-g0-protocol-final/seed-0-repeat-0/G0` 的原始工具、公开帧、机器人测量与抓持注册。在线代码未使用 trace 中的物体真值。

- 原 Can 放置阶段：48 次候选求解对应 **12 个唯一端点，重复 4 轮**；共 384 次 IK 迭代。末次位置残差 29.72–83.66 mm，超过原 1 mm 门限。布尔 reachable 丢失了这些差异，随后恢复继续重复同一搜索。
- 保持原几何余量，测试 4 个直立 yaw、共 48 个候选，仍无解。重复搜索命中 48 次精确 IK 缓存，没有新增求解。这不是“整片容器不可达”的证明。
- 独立标记的姿态诊断：第 21 个候选（40° 倾斜）获得放置端点和上方端点解；位置残差分别约 0.000269 / 0.000162 mm，旋转残差约 0.0000134° / 0.0000176°。阈值未变。此候选明确是 **DIAGNOSTIC_ONLY**，并未获得释放或路径许可。
- 几何计算保留物体相对 TCP 的偏移、旋转后的包围范围、原 XY 不确定性与 25 mm 边界余量。该倾斜候选不能证明实际持物不会滑移，也不能证明释放后稳定。

证据：`can-zero-llm/diagnosis.json`、`ik-results.json`、`portable-mature-probe/results.json`。

## 成熟算法的真实接入与限制

1. 当前 PyRoKi `/plan` 调用线性 IK 插值，接收的 obstacles 没有进入该算法；不能将其标为碰撞感知规划。
2. 本地 `_trajopt.py` 确有成熟 PyRoKi 碰撞/平滑优化。本轮实际调用，原接口重新求解起点 IK，轨迹起始关节与提供的起点相差 **0.817 rad**，不能执行。
3. 增加可选公开起始关节参数并复用已有优化成本；新模式补充整条轨迹自碰撞成本，旧 pose-only 模式保留。用真实归档编码器作为起点，误差降至 **6.01e-7 rad**，终点误差约 **0.464 mm / 0.235°**，通过原端点门限。
4. 上述优化仅使用公开地面等有限障碍；原机器人碰撞模型没有可靠纳入持物。因此返回 UNKNOWN，permission=False。没有把软碰撞代价最小化当成安全证明。
5. 使用归档的真实 RGB-D、配置机器人几何、持物模型及原 `observed_free` 检查扫掠采样。第二段需要检查的 84,536 个新增点中，11,990 个具有当前自由空间证据，43,718 个缺少有效可见深度；结果 UNKNOWN。**未知和占据未被混淆为同一种物理碰撞结论。** 未取消保护。
6. cuRobo 模块未安装。宿主机只读检查确认 NVML 驱动/库 580.178 不匹配，PyTorch CUDA 初始化报 Error 804。没有修改驱动、升级依赖或停止已有 SAM3/GraspNet/IK 服务。

最新补充的空间关系编码与开放运动失败诊断返回通过机制回归；上述物理运行之后没有以这些纯反馈字段再发起新物理实验。各次运行的 source-postcheck 均为空，版本区别由各自源码归档保留。

`public_planning.py` 是无执行副作用的成熟算法适配器；**尚未接到 run_plan 的完整轨迹派发**。PublicJointSweep 在原开放运动和成熟 Skill 间的准入范围差异仍存在。统一运动底座尚未完成，不能声称本轮已解决第 7 项全部要求。

## 已修改的接口

- `preplanning.py`：纯候选生成、原有 IK 搜索/诊断、正负结果精确缓存、后续放置条件性可行性、轨迹起点/终点校验。实际碰撞和释放检查独立。
- `open_recovery.py`：新增 preview_skill / planning_query / decision_state；plan_skill 对 acquire/deposit 做实际搜索；旧计划在运动或附着变化后拒绝。默认响应精简，完整详情按 ID 查询。
- `decision_state.py`：编码目标、对象几何来源、名义附着变换、空间关系、候选残差和剩余搜索；不直接倾倒全部 Belief 或点云，不把历史估计伪装为当前许可。
- `native_vision_skills.py` / `bounded_ik.py` / `layered_feedback.py`：保留被审计包装器遮住的 IK 诊断，并记录 solver reference、关节限制与逐次残差。reference 是速度代价的参考，不冒充优化器初值。
- `vision_skills.py`：V35 放置比较多个直立 yaw；预抓取检查对后续放置的影响，抓取后使用当前注册重新计算。不保证一次有限搜索找到最佳抓法。
- `grasp_geometry.py`：保留 GraspNet 完整变换并给出显式轴映射和配置 TCP 偏移的候选假设。上游 build_6d_grasp 在接触中点减去 0.1034 m 深度，原始平移不能直接作为 TCP。完整六维候选还没有通过真实接近/抓持验收，不自动启用。
- `unified.py` / `contract_models.py`：统一入口支持 `--decision-encoding legacy|encoded`；两组使用相同 V35 能力，历史/手写程序的来源与新增模型调用分别记录。
- `harness_probe.py` 与三个诊断脚本：复用现有 Runner，新增明确标记的受控公开程序和可复跑离线探针。

此外新增 V35 配置、12 个机制测试、使用说明和本报告；V34 既有未提交修改仍保留。没有改动物理评分、Sandbox、API key 或释放门限。
