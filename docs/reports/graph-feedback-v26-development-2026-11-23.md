### 失败根因及决策归因

**Seed 0：附着关系变化与恢复能力缺口。** 两组初始物理轨迹一致，Milk 已完成搬运和稳定放置。Bread 抬升约 **0.17755 m**，物体旋转 **18.295°**，同期 TCP 旋转仅 **0.052°**；相对转动下界约 **18.243°**。这是独立物理 Trace 的离线结果，没有传给在线系统。它证明原附着假设变化，不能据此断言已经掉落。当前 RGB-D 注册无法确认原刚体附着，保持 UNKNOWN；当前技能又缺少合格的附着重估/安全卸载能力。

G0 刷新证据后明确退出。G1 连续要求 `deposit-1`，三次因前置条件不成立被拒绝，最后耗尽程序块预算。生成代码及模型记录显示它尝试依赖父进程重新检查，而没有先获得持物确认。图没有使这一决策更有效；不能把“被安全拒绝”计作恢复成功。

**Seed 21：共享的区域几何前置失败。** 真实 SAM3/RGB-D 不能建立所需的有界容器壁面配对，返回 `missing_bounded_wall_pair`。两组都重复了无信息尝试并在 4 块上限退出。这里还暴露出图契约过粗：acquire 的显式前置主要是 `robot_ready`，工作区几何失败仍在 Skill 内部，图尚不能充分解释所有分支共享的感知阻塞。不能把这一问题全部归咎于 LLM，也不能说图已覆盖全部几何依赖。

## 证据过期压力测试与局部消融

在第一次公开验证的目标完成后，仅使其图证据过期；不移动物体、不改变评分。在线系统看到的是条件失效，不接收故障标签或仿真真值。5 组共享这次初始模型程序及 Snapshot。

|---|---|---|---|---|---|
| G0 | 否 / 1/4 | 成功 | 28 / 32 | 4 | 257.09 |
| G1 | 否 / 1/4 | 成功 | 26 / 32 | 4 | 241.65 |

五组均通过新公开观测恢复过期条件，并执行了 **6 次后续控制原语**，没有重新搬运已完成的 Milk。随后仍被 Bread 的持物不确定性阻塞，完整任务全部失败。

真实图变化：`placed:Milk` 原节点失效 → 模型恢复代码请求补证 → 当前 RGB-D 确认目标 → 新版本条件为 TRUE → 保留已完成调用历史、继续另一分支。G0 第一次补证范围为 8 个条件；G1 为 `held:Milk`、`placed:Milk` 两项。**范围确实变小，但 capture 均为 32，SAM3/GraspNet/IK 请求分别均为 198/2/39。** 少 2 个外层 API 不足以证明恢复效率提升，尤其 G1 后续仍存在无效放置尝试。

另一个真实物理恢复案例是 Milk 释放前的几何区间不合格：原 Skill 根据当前观测局部对齐一次，重新验证后释放，原生评分确认该物体入箱。7 个发生运动的 episode 均出现这项共同能力。**它属于 G0/G1 共用 Skill 的收益，不是图的增益。**

消融边界：`no_future` 只关闭图的下一工作建议，不删除共同安全契约；`no_memory` 只强制复核原本保留的目标证据，仍保留安全所需的几何模板/附着估计。它们不是完整 Future Intent 或几何记忆的移除实验。每种仅一个压力场景，不能从某次 LLM 请求较少推断组件无用或有效。

## 请求、费用、工程失败与测试

最终主实验：**26 次唯一真实请求，全部 HTTP 200**；输入 **75,177** Token，输出 **90,175** Token，其中 reasoning **87,430**；项目口径费用 **US$0.456327**。严格校验响应模型和完整响应，reasoning 不作为 Python 执行。请求成功不等于物理任务成功。

此前两个工程试跑另外发起 8 次请求：7 次收到回执，1 次停止试跑时未取得回执，保留为未确认请求，没有自动重试。已知请求（含调试）估算 **US$0.719032**；加上未确认请求预留费用后的保守记账上界 **US$0.872628**。单价沿用项目估算规则（每百万输入/输出 Token 为 1.32/3.96 美元，未扣缓存优惠），不等同于服务商账单。

工程失败均保留在 `normal-seed0/` 和 `paired-v26-seed0/`，不混入上述完整配对：发现并修复了 API 返回 schema/受限方法说明不足、日志 `kind` 冲突、NumPy 控制台序列化，以及无安全续接时反复请求恢复的问题。它们不是被删除的失败模型样本，而是接口仍在修改时未完成的工程单元；消耗已计入总账。
