回归器只读通用目标、条件规格、生产效果和顺序约束；新方法没有按任务名、颜色、对象名、Seed 或故障标签分派恢复。任务定义仍提供对象绑定，当前真实技能覆盖仍限于单臂区域 acquire/deposit。关键词审计和角色替换测试支持这一实现边界，不等同于任意任务的通用性证明。

TRUE 条件可以保留；UNKNOWN 优先询问当前公开证据；FALSE 回归能够产生该条件的声明技能；无能力、依赖环、未知物理效果或预算耗尽时停止。独立的未知条件合并到同一帧补证，共享的不可恢复前置会截断无用分支。真实运动可重新开放补证机会，静止重复帧不可以。

修复意图必须使用新 ID，已完成调用不能重放；图选择工作范围，不直接把图拓扑当成机器人路径。模型仍生成恢复 Python，父进程在真实调用时重新准入。**本轮在线新修复 ID 数为 0**：这一能力通过了机制测试，但在线主要发生补证、未执行意图续接和无能力退出，不能写成已经验证了失败 Skill 的物理重做成功。

### 证据过期：恢复证据并继续，未完成物理任务

第一次目标完成后，`placed:Milk` 证据失效。G1 的真实路径为：先回归并补证目标 → 当前公开几何确认 Milk 仍已放好 → 保留完成历史 → 补齐剩余分支的 held/target/geometry/grasp_ready → 父进程只允许 `acquire-1` → 新 DeepSeek 程序执行 → Bread TCP 不收敛。

随后图保留已经得到的兄弟条件，尝试允许独立的 `acquire-2`；真正派发前的最新检查发现 workspace/geometry 不足，拒绝动作，最后有界退出。**保留的证据并不保证最终可执行；不能用保留节点数量宣称实际节省。**

四组都恢复了过期目标证据，并执行 6 次后续物理控制原语，没有重做 Milk 搬运。G1 与 G0 均 3 次逻辑 LLM；G1 多 3 次 capture、16 次 SAM3（228 对 212）。no-selective 只需 2 次 LLM。该场景不支持选择性补证更省成本。G1 的多层条件前沿虽然正确，却可能比一次全后缀补证更昂贵。

### 物理扰动：一次极端注入和一次局部注入分别报告

初版外力对 0.020824 kg 轻物体过大：6 N 水平、12 N 竖直，持续 0.12 秒，再等待 0.5 秒，将物体抛离原位置 **30.352 m**。原生目标由 1/4 变为 0/4。这是实验设计问题；保留为极端不可恢复压力结果，不能拿它证明局部恢复能力。

另立配置，按质量及预声明速度增量 `[0.5, 0, 0.25] m/s` 计算外力，仅运行一次完整四组单元。共同控制器和安全阈值未变。实际位移 **19.959 mm**，原生目标仍为 1/4，因此这次只覆盖局部状态/证据变化，**没有成功破坏已完成目标，也没有目标修复成功**。没有为达到期望结果继续搜索力值或 Seed。外力施加与等待会推进全场仿真时间，这也可能影响后续接触；正常/压力结果不混合估计效果。

两种压力下 G0/G1 都继续到 Bread 获取阶段，最终 `closed_unverified`。公开持物注册创新约 **17.587° > 8°**，95% 残差约 2.678 mm、覆盖率 1.0；覆盖率高不代表原附着变换仍成立。系统保留 held UNKNOWN，不重置附着关系，不盲目释放。G1 在缺少合格附着恢复能力时直接停止，少发后续无效请求，但没有恢复物理抓持。

极端外力的 G0、局部扰动的 no-graph-repair 各有一次模型使用禁用变量 `obs`，Sandbox 在零 API 调用时拒绝。相应额外 LLM 费用全部计入，不能把这些代码错误造成的请求差都解释成图规划优势。

### 哪些实际收益属于共同底座

所有发生搬运的 16 个最终 episode 都出现 Milk 释放前的共同局部对齐，原生评分确认曾完成该子目标；它来自同一 Vision Skill，不是图新增收益。最终版中所有六个四组单元都有限结束，没有跑满预算来等待偶然成功。

图独有的已见收益限于工作范围约束和部分无能力边界的模型调用节省；尚未看到更高物理成功率、修复后新增完成目标，或可重复的选择性感知成本优势。状态记忆与 Future Intent 的独立贡献本轮无法识别。

## 是否扩大评测

**暂不扩大正式评测。** 有界执行、共同安全和图授权工作范围已有机制与真实链路证据，但完整四目标成功仍为零，失败 Skill 的物理恢复尚未通过。现在扩大只会大量重复容器几何、邻物几何、控制净空和附着确认瓶颈。

下一步应在固定开发条件下补齐经过公开感知验证的附着重估/安全处置能力，细化共享障碍与目标几何依赖，并先取得两个以上独立子目标及一次真正可恢复的物理失败案例。之后再检验图是否减少相同进展下的重复工作。不要以增加任务特判、放宽原阈值、筛 Seed 或继续无信息观察替代这项验收。

当前证据支持“G1 能限制合法恢复范围并在缺少能力时有限退出”；不支持“图已提高长程任务成功率”“选择性恢复普遍更省”“已修复 Bread 附着问题”或“已完成被破坏物理效果的恢复”。
