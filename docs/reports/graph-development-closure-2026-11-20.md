## 本次定位与修复

1. **G0 日常读与异常失效混淆。** 普通源更新曾把已消费计划、历史检查一起作为附加失效根，沿历史事实误伤刚获得的持物证据。现在日常读只额外废弃有效且未消费的计划；真实异常仍保守废弃未执行后缀，真实运动仍使旧位姿及撤退计划失效。
2. **桌面位置意图与一次性许可混淆。** `reobserve_table` 曾让新区域依赖会在下一次运动后过期的检查。现在区域保留当前观测/校准与历史意图来源，历史检查 ID 用于诊断；每个实际放置运动边界及释放重新获取当前许可，旧许可不能直接授权后续动作。新的 robot read 复用既有 context 重建机制，不复活旧计划。
3. **深度采样与射线约定不一致。** 当前实际渲染上下文使用 4 倍 MSAA、固定样本深度解析。独立 scratch 探针从当前上下文测量样本位置及解析规则，不从任务几何拟合补偿。RGB 与深度约定分别记录；未知规则拒绝提供几何许可。
4. **夹爪视觉网格的微小 FK 轮廓误差。** 机械臂继续使用关节 FK；配置中的夹爪网格使用当前公开 TCP 与静态偏移，两个手指仍要求独立编码器。原 FK/TCP 一致性门槛与首个表面 2 mm 匹配阈值不变。
5. **缺失渲染校准的错误类别。** 专用异常归为基础设施错误，而不是模型程序错误；退出不能计为成功，也不通过 LLM 重规划尝试修复驱动/渲染条件。
6. **离线桌面误报/漏报覆盖。** 新增独立桌面 footprint 标签：只从记录的区域 ID 取待检查范围，用父进程保存的实际桌面边界与当前非持物方块 AABB 判断区域占用。未知证据保持 unknown，不读取在线 mask/PASS 作为真值。

深度修复的离线证据在 `depth-calibration-v9/`：真实 GL 正常及故障路径保持原 RGB-D 字节和 GL 状态；v7 冻结帧的 15 个灰点均匹配机器人首个表面（最大射线误差 2.46 µm），暗点仍未知，人工前后外物被拒绝。这是离线光学校准验收，不能替代新版本在线操作结果。

桌面标签是有限的几何风险代理：不证明整臂/路径安全，不认证桌面高度估计，竖向投影 AABB 会保守覆盖悬空非持物。V8 按该代理有 G0 两次、G1 五次误阻断；同一场景重复检查不能当作独立样本或整体检测准确率。
